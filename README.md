# FinPlusAnalytics_TeamArdillas
Trabajo final Fundamentos de Big Data

# Descripción del proyecto:

El proyecto se estructura siguiendo un pipeline de datos end-to-end, es decir, un proceso integral de principio a fin formado por varias etapas hasta alcanzar una solución completa, robusta y escalable. Este flujo de trabajo permite transformar sistemáticamente los datos brutos en insights de negocio accionables, recomendaciones estratégicas y un plan de mejora para la empresa FinPlus.

Tras una fase inicial de análisis de negocio exhaustivo, la profunda comprensión del contexto de la empresa
y la definición clara de los objetivos que se abordarán como consultoría especializada, se procede al diseño
y ejecución de un proyecto estructurado. Este se compone de múltiples fases secuciales en las que se emplea un conjunto de arquitecturas modernas, herramientas especializadas con el fin de crear un plan de negocio óptimo para FinPlus.


# Instrucciones para replicar el entorno y ejecutar el pipeline:

En primer lugar, es importante tener instaladas las aplicaciones Visual Studio Code, GitHub Desktop y Docker, poseyendo las respectivas cuentas en cada app. A continuación en la página web de GitHub, uno de los miembros del equipo debe crear un repositorio para este trabajo final, lo adecuado es cambiar los ajustes para que sea público y los demás puedan acceder a partir de la ruta del repositorio. Para poder empezar, deben descargarse los archivos csv proporcionados por el profesor. Una vez seguido todo este proceso, cada vez que un miembro del equipo quiera escribir código, debe realizar los siguientes pasos:
1. Abrir Github y Docker.
2. Realizar un pull desde github, descargando así la ultima versión.
3. Abrir Visual Studio y levantar docker (como lo aprendido en clase)
4. Trabajar (escribir código)
5. Cuando se finalice el trabajo en Visual Studio, es conveniente guardar todo con un control save, y para acabar, realizar un commit, y un push, es decir, empujar a la nube la actualización

Cada vez que uno de los miembros del equipo quiera trabajar en el proyecto final, debe seguir estas instrucciones.
